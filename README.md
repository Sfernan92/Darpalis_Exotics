# Darpalis_Exotics
Darpalis Exotics es una propuesta de página web, actualmente en producción, para una tienda especializada en animales exóticos y en productos para su cuidado responsable. Incluye un catálogo de terrarios, hábitats, alimentación, iluminación, climatización y accesorios para reptiles, invertebrados y otras especies. Ofrece información útil.
